# Pitch / presentation outline

1. Problem: keyword resumes and noisy generic job boards.
2. Product insight: reverse recruitment + verified evidence, not resume self-description.
3. Candidate journey and `.ru`/Keycloak identity flow.
4. Calibrated unique assessment: different forms, comparable difficulty, no grade-collapse.
5. Anti-leak / anti-AI-by-design: progressive verification, session-specific artifacts, advisory integrity signals.
6. Verified Skill Passport + synthetic FSP achievements as bounded positive evidence.
7. Talent Radar: employer starts from categories, not a flat resume board.
8. ProofMatch / Evidence-Graph Reverse Matching: score, confidence, reasons and gaps; unconfirmed grade remains visible.
9. Invitation with salary upfront → accepted MATCH → internal chat/contact unlock.
10. Employer Hiring Pipeline: extra employer-authored/graded stages; optional CPU-local task copilot using prior approved tasks.
11. 152-FZ-oriented privacy controls and minor-consent flow.
12. Validation: matching metrics vs keyword baseline + assessment confusion/stability/discrimination.
13. Load test on CPU-only target host; no GPU dependency.
14. Architecture / Keycloak / Docker / OpenAPI / local adapters.
15. Brand-responsive UI and Telegram autonomous-development evidence/screenshots.
16. Live demo.
17. Roadmap: real FSP registry/Keycloak integration, ATS, employer trust.

Keep the core 35% matching criterion and 25% assessment criterion central in the narrative.
