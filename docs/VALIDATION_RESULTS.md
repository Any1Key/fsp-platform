# Validation results

Status: **MEASURED — local synthetic matching and assessment runs**

The canonical machine-readable result is [`VALIDATION_RESULTS.json`](VALIDATION_RESULTS.json).
It is generated by the aggregate report command below and is committed so a
reviewer can inspect the exact fixed-seed output without trusting copied
figures in this page.

## Reproduce

From `backend/`:

```sh
PYTHONPATH=. .venv/bin/python -m app.validation_report \
  --output ../docs/VALIDATION_RESULTS.json
```

The report composes three offline, CPU-only sources:

- the 80-candidate/20-need versioned fixture and its 1,600 labeled pairs;
- the label-free keyword/Jaccard matching baseline; and
- the calibrated assessment harness with 24 synthetic profiles per grade.

The fixed seeds and source versions are recorded in the JSON artifact. The
aggregate writer is covered by `backend/tests/test_validation_report.py` and
does not access PostgreSQL, HTTP routes, production candidates, or employer
data.
