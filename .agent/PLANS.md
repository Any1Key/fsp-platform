# ExecPlans

Use an ExecPlan for work that spans multiple modules, adds migrations, changes public API,
or is expected to take more than a small edit.

Path: `.agent/plans/<milestone-or-task>.md`.

Minimum sections:
- Purpose / user value
- Requirement IDs
- Current behavior
- Proposed design
- Files/modules
- Data/API changes
- Security/privacy implications
- Test plan
- Demo/evidence
- Progress / decisions / surprises

Keep plans concise and update them during implementation.
