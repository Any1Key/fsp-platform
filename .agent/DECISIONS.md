- ADR-001: modular monolith for hackathon reproducibility.
- ADR-002: Keycloak/OIDC from the start.
- ADR-003: assessment = calibrated blueprint + templates + variants + anchors.
- ADR-004: matching = transparent weighted score + reasons.
- ADR-005: FSP = bounded positive bonus, never hard gate.
- ADR-006: responsive UI is project P1 despite source saying optional.
- ADR-007: external supervisor owns verification/recovery.

## 2026-10-06 conference clarifications

- Base grade assessment remains platform/system-scored.
- Employer-authored tasks are employer-graded and produce employer-specific evidence by default.
- Anti-AI is implemented through assessment design and advisory integrity signals, not an automatic AI detector.
- Synthetic validation checks grade discrimination; it must not force quotas/curves.
- Accepted invitation is the default `MATCH_CREATED` event unlocking internal chat.
- Unconfirmed declared grade remains searchable and explicitly labeled.
- Local AI is optional CPU-only assistance; retrieval from approved employer tasks is preferred to fine-tuning on the NAS.
- Minor consent workflow is configurable and legally reviewable; age is excluded from ranking.
